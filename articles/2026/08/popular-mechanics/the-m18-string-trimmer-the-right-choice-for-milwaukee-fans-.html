When it comes to string trimmers, there are plenty of models to choose from, and most will do the job. How do you pick one from a selection that all seem to do the same thing? Sometimes when you’re shopping for cordless tools, the best decision is to choose one from the platform you’re already on. Case in point: Milwaukee’s cordless M18 2828-21E String Trimmer. If you’re on their M18 battery platform, and you need a string trimmer, this one checks the boxes.

M18 2828-21E String Trimmer: What It Does

High/low speed selector—featuring turtle and rabbit icons—let’s you choose faster cutting speed or longer run-time.

This is Milwaukee’s least expensive string trimmer, and as such it doesn’t have a lot of bells and whistles. It has two main features that are worth mentioning though. The first is a high/low speed selector, which either gives you maximum cutting speed or longer runtime. The second is probably the most important feature: an easy-load trimmer head. And it is really easy to load. Just line up the index marks on the head, feed a length of string straight through, and then wind the string into the head.

An easy load trimmer head makes loading the string a breeze.

As far as performance, the M18 2828-21E String Trimmer has the power to cut through overgrown weeds, in addition to trimming the edges of the lawn you can’t reach with a mower. You’ll be able to get a little more than a half hour of trimming with the included 6 amp-hour battery—that’s not total runtime, but the time it took me to walk around the yard and trim all the different areas that needed trimming.

Who It’s For

The M18 2828-21E String Trimmer is best suited for folks already on the Milwaukee M18 battery platform. If you have M18 batteries, you could save some money and buy it as a tool only. In most cases I wouldn’t recommend cherry-picking tools across multiple platforms, creating a situation where you have to manage multiple chargers and batteries. You’ll also eventually run into a situation where you have charged batteries available, but not for the tool you need now. For basic tools like this M18 2828-21E String Trimmer, I would recommend sticking with your platform.

What If You Need to Do More Than Trim Some Edges After Mowing?

As I mentioned, the M18 2828-21E String Trimmer is a basic tool. If you need to cut heavier brush or need more versatility, you should consider stepping up to the 2825-21ST M18 String Trimmer. It has more power, comes with a bigger 8 amp-hour battery, and features a Quik-Lok attachment system that allows the trimmer head to be swapped out with up to 13 different tools.

The Verdict

The M18 2828-21E String Trimmer is a good option for folks on Milwaukee’s M18 battery platform and who need a basic trimmer. It does exactly what it’s designed to do, and can be bought as a tool only.

I open Instagram to check out my friends' Stories, updates from my local community, and the latest dog video my wife sent me last night. But after doing all of that, I find myself doomscrolling for hours. It got so bad, I ended up deleting the app and using the website exclusively. It's a similar story on YouTube, where I end up scrolling through endless Shorts. When YouTube’s Shorts limit came out, I rushed to enable it.

But I’ve found a better solution for both apps, at least for my Pixel. There’s a setting hidden deep inside the Switchly app that blocks certain addicting elements of popular apps. Switchly is completely free, open-source, and doesn’t show ads: Its main job is to serve as a free and open-source alternative to devices like Brick. It blocks apps and websites to help you focus, and the only way to unblock is by using an NFC tag and a QR code—the Android equivalent of the Foqos iPhone app. Here's how it works.

Switchly can block reels, the Explore page, comments, and Stories on Instagram. On YouTube, it can block Shorts, the Subscriptions page, the "You" tab (YouTube's recommendation feed), and picture-in-picture mode. On X, it can block the home page, search, Grok AI, or notifications. On Snapchat, you can disable the Map, Stories, Spotlight, or the Following page. You can really disable the features that distract you the most. For me, that’s reels, search, and comments on Instagram, and Shorts and the You page on YouTube.

Switchly is an app blocker, so it needs accessibility and screen access permissions before it can work. Because it’s a free and open-source app, with code hosted on GitLab, third-party testers can verify Switchly's security, so I find it safe to use.

Once you grant the app the needed permissions, go to the Blocking tab, then go to the In-app blocking section. Here, enable the features you want to block in each app (this will only work if Switchly’s global blocking is currently disabled). After that, go to the Home page, and from the top, tap Enable. The blocking will now be enabled until you disable it manually.

If, like me, you want to ban these features forever, you can leave it at that. But if you only want to disable them during work hours or on weekdays, you can set up a schedule. If you would like to block certain apps and websites, you can add them from the Manage Apps and Blocked Websites sections. To set up a schedule, go to Manage > Schedules, tap the Plus button, create a new schedule, and customize it to your needs. As we discussed earlier, the app offers many more ruthless options for controlling the block. You can go to Blocking > Blocking Controls to switch to a different blocking method.
